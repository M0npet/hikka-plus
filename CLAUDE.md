# Hikka Plus — правила для Claude

Розширення для hikka.io (WXT 0.21 + React 19 + TypeScript, MV3 для Chrome, MV2 для Firefox).
Мова маніфесту за замовчуванням — українська (`default_locale: "uk"`, назва й опис — `public/_locales/{uk,en}/messages.json`, 0.6.1).
У збірці замість React — **Preact** (`preact/compat` через alias у `wxt.config.ts`, 0.5.17): код пишемо як під React (типи `@types/react`), але лише API, які є в compat (хуки, `createRoot`, `useId`, `useSyncExternalStore`); content script 429 → 224 КБ. Перевірено попиксельно проти React-збірки (блок плеєра, «Ширше», читалка, вікно налаштувань).
Карта проєкту й рішення MK — у claude.ai-проєкті «Hikka The Project» (`claude/project-map.md`,
`claude/research-readers-and-layout.md`).

## Рішення MK (не порушувати)
- Усе вбудовано в сайт і в його стилі; блок розділів і кнопка — на сторінці тайтлу, читалка — оверлей.
- Джерела — **тільки українські**: Zenko, manga.in.ua, baka.in.ua, Honey Manga, UAManga, DGManga, Animesvit, Смаколики, Runi, NovelHub (novel.org.ua; роботи 18+ сайт віддає лише після входу — не показуємо), FanVers (fan-vers.com, лише переклади), Wattpad (лише історії українською, language 46; платні — ні). Захист читалки (токени, nonce, Referer) не обходимо — такі сайти лише посиланням: `src/sources/links.ts` (Mangra — точно за `hikkaSlug`, FAUST і Mangarama — публічний пошук, Dengeki — посилання на пошук; спершу завжди посилання з блоку «Читати» на Hikka), UI — `src/features/external-links.tsx`. Повний список сайтів і чому деякі не підключені — `claude/sources-ua.md` у claude.ai-проєкті. Senkuro — лише зразок UX.
- Без власного сервера. Віддалено можна оновлювати лише дані (JSON), не код (політики AMO/CWS).
- Не заважати Hikka Features і Hikka Forge: тільки свій Shadow DOM з тегами `hikka-plus-*`,
  класи `hp-*`, чужий DOM не змінювати, клавіші перехоплювати лише при відкритій читалці.
- «Свої тайтли в каталозі» — відкладено, не робити.
- Назва: Hikka Plus, неофіційне; не видавати себе за Hikka.

## Структура
- `entrypoints/background.ts` — fetch за allowlist (`src/core/hosts.ts`), CORS обходимо тут.
- `src/core/net.ts` — запити з content script через background. 429 → `HttpError(429, RATE_LIMIT_TEXT)` («Сайт просить почекати — спробуйте за хвилину») і пауза на хост (`Retry-After`, інакше 60 с, ≤10 хв): поки пауза — запити до хоста не йдуть. У `catch` пошуку/автопідбору — `rethrowRateLimit(e)`: 429 не можна ковтати як «не знайдено» (`title-state` інакше запише `misses` на 3 дні). Бака: сторінка тайтлу в кеші 60 с, `getLatest` — лише найновіший том.
- `entrypoints/content/` — монтування блоків (`src/core/mount.ts`, self-healing для SPA), стилі `style.css` (`:hover` — лише всередині `@media (hover: hover)`, інакше на дотику «липне»; вузький плеєр — `@container hp-view`).
  Зміну сторінки в SPA перевіряти за `location.pathname` ідемпотентно: подія `wxt:locationchange` (Navigation API) приходить ДО оновлення адреси.
- `src/features/title-state.ts` — спільний стан тайтлу (кнопка, блок, читалка). Повний список розділів — лише в активного джерела (обране або найпріоритетніше з прив'язкою); неактивні з дешевим `getLatest` (UAManga, Honey Manga, Бака; `ReadSource.latestIsFull` — manga.in.ua, там і так усе одним запитом) — лише найновіші (`SourceState.partial`, на плашці «~N» = `lastChapterNo`), повний довантажує `loadFullChapters`, коли джерело стає активним або його відкриває `#read=` (MK 2026-11-27).
- `src/sources/` — джерела (`ReadSource`), автопідбір (`match.ts`, `autoMatchBy` — спільний для нових джерел; підсумок завжди через `settleMatch`: кандидат 0.45–0.8 → підказка «Схоже» в блоці, прив'язка лише по кліку, «Ні» — `Binding.nearNo`; кнопка «Відв'язати» в шапці «Розділи» — `unbindSource`: прибирає прив'язку активного джерела й записує її в `nearNo`, тож автопідбір цей тайтл більше не прив'язує).
- `src/core/hikka-auth.ts` + `hikka-api.ts` (лише background) — OAuth Hikka і PUT /read; `src/features/hikka-sync.ts`, `hikka-bar.tsx` — синхронізація лічильника (`setHikkaChapters` — лише вгору; відмітка, що не дійшла (мережа, закрита вкладка), — у `local:hp:hikkaRetry`, дошлеться `retryHikkaChapters` при наступному заході на тайтл; ручне зниження її скасовує (MK 22:30); ручне зняття «прочитано» → `lowerHikkaChapters` до останнього розділу, прочитаного поспіль; скидання в «Дані» Hikka не чіпає).
- `entrypoints/hikka-bridge.ts` — скрипт у контексті сторінки (`injectScript`, web_accessible лише для hikka.io): після нашого PUT /read подія `hikka-plus:read-changed` (`src/core/bridge.ts`) → `invalidateQueries` у QueryClient самої Hikka (знаходимо через дерево React) для запитів з `read` в `_id` — віджет «у списку» оновлюється без F5. Зворотно: міст підписаний на кеш запитів Hikka — успішне оновлення `readGet`/`watchGet` (напр. «+/−» у віджеті Hikka) → подія `hikka-plus:hikka-list-changed` → `loadRemoteRead(..., quiet)` у `title-state.ts` → hikka-bar відмічає 1–N. Лічильники з віджета Hikka без нашого входу: `watchGet` → `WATCH_COUNT_EVENT` (сітка серій), `readGet` → `READ_COUNT_EVENT` (`hikka-bar.tsx` відмічає 1–N). DOM Hikka не змінюємо.
- Плашки на картках аніме (MK 18:26, як на Mikai) — `src/cards/`: «▶ N нових» (`episodes_released` − переглянуті, лише статус «Дивлюсь») — з кешу самої Hikka: міст збирає знімок (`CARDS_EVENT`, `collectCards`: `searchAnime`/`animeSchedule` — поле `watch` того, хто зайшов; `userWatchList` — лише власний список за `profile.username`; `watchGet`), без запитів; «N серія через X дн.» — `schedule.ts`: POST `api.hikka.io/schedule/anime` 2 сторінки × 100 (`ongoing`+`announced`), кеш `local:hp:schedule` 3 год. `cards.ts`: свій `<hikka-plus-badges>` (Shadow DOM без Preact, `pointer-events:none`) у `div[data-slot=aspect-ratio]` постера (внизу зліва) або після назви в таблиці списку. Вимикачі — `local:hp:cards` {on, next}, вкладка «Плеєр».
  Манґа/ранобе (0.6.1): «▶ N нових розділів» = останній розділ на прив'язаному джерелі − прочитано в Hikka, лише статус «Читаю» (`reading`). Прочитане — той самий знімок мосту (ключ `<manga|novel>:<slug>`: поле `read` у `MangaResponseWithRead`/`NovelResponseWithRead`, записи списку читання `{content, chapters, status}` — лише свій за `profile.username`, `readGet`). Скільки вийшло — `released.ts` (`local:hp:released`, ≤400): `noteReleased` при завантаженні розділів активного джерела + команди (підписка в `title-state.ts`), `refreshReleased` з content script — лише видимі тайтли «Читаю» з прив'язкою, раз на 3 год на тайтл, ≤8 за раз, замок `local:hp:releasedLock` між вкладками; без прив'язки — без плашки. Вимикач `CardsPrefs.read` — вкладка «Читалка».
  Українські постери аніме/манґи/ранобе (MK 2026-11-25: «везде», за замовчуванням вкл., вимикач — загальний, вкладка «Hikka» → «Сайт Hikka») — `src/cards/covers.ts`. Аніме: Mikai `images.uaPoster` (україномовні постери, напр. команда uaposters), пакетом `GET api.mikai.me/public/v1/anime/batch?source=hikka&ids=…` (≤100, `wantAnimeCovers` з `renderCovers`, не частіше ніж раз на 2 с; «немає» — 3 дні), `u` = medium, `b` = big для сторінки тайтлу, `a` — автор. Манґа/ранобе: обкладинка лише з ТОЧНО ПРИВ'ЯЗАНОГО джерела (MK 2026-11-25, варіант A: ручна прив'язка, автопідбір за посиланням «Читати» з Hikka або назва ≥ `EXACT_MIN` 0.95 — `RemoteTitle.exact` → `SourceLink.exact`; прив'язки до цього без позначки — перевірка назви в `noteCover(…, names)`; «Схоже»/неточний автопідбір — без постера, крім вибору в меню «UA»), `COVER_SOURCES`: манґа Zenko → Honey Manga → DGManga → manga.in.ua, ранобе Бака → Honey → DGManga (UAManga/Animesvit — оригінали; розвідка `claude/research-ua-posters.md`); `noteCover` після завантаження тайтлу й ручної прив'язки (`getTitle`, раз на 14 днів), кеш `local:hp:covers` {u, s, id, at, o?, p?} ≤1000; Zenko — `width=480`. Показ у `cards.ts` (`renderCovers`): `<hikka-plus-cover>` (Shadow DOM, `<img referrerpolicy=no-referrer>`, pointer-events:none) одразу ПІСЛЯ блоку з картинкою Hikka в `div[data-slot=aspect-ratio]` (картка: `> a`, сторінка тайтлу: `> div.@container` у `#content-left-side`) — поверх картинки, під значками Hikka; якщо `img` постера не з hikka.io (підмінило інше розширення) — не чіпаємо. Вимикач `CardsPrefs.ua`; на самому постері (картка й сторінка тайтлу) — кнопка «UA» справа внизу (MK 2026-11-25; плашки зліва звужено `right: 58px`, щоб не налазили) → меню «Постер»: «Оригінал Hikka» (`o: 1`, кнопка — темне скло) або джерело постера — аніме: Mikai; манґа/ранобе: будь-яке ввімкнене джерело з прив'язкою (`Cover.p`, `setCoverSource` → `noteCover(…, force)`; немає обкладинки — «На … немає обкладинки», вибір не змінюється; без `p` — за `COVER_SOURCES`); на мініатюрах < 90 px кнопки немає (container query).
